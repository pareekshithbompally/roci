## Default Permission

Allows all Apple Intelligence commands (on-device language model + speech)

#### This default permission set includes the following:

- `allow-availability`
- `allow-generate`
- `allow-speech-status`
- `allow-speech-request-access`
- `allow-speech-prepare`
- `allow-speech-transcribe`
