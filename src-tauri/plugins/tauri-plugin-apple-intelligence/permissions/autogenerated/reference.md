## Default Permission

Allows all Apple Intelligence commands (on-device language model + speech)

#### This default permission set includes the following:

- `allow-availability`
- `allow-generate`
- `allow-generate-cancel`
- `allow-stream`
- `allow-stream-cancel`
- `allow-speech-status`
- `allow-speech-request-access`
- `allow-speech-prepare`
- `allow-speech-transcribe`
- `allow-speech-live-start`
- `allow-speech-live-feed`
- `allow-speech-live-finish`
- `allow-speech-live-cancel`
