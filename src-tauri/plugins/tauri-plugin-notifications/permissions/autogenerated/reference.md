## Default Permission

macOS notifications: permission, posting, timed notices

#### This default permission set includes the following:

- `allow-status`
- `allow-request`
- `allow-post`
- `allow-schedule`
- `allow-remove`
- `allow-add-categories`
- `allow-set-muted`
