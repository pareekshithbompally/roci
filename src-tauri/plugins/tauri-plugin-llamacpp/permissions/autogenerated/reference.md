## Default Permission

Allows all llama.cpp plugin commands

#### This default permission set includes the following:

- `allow-spawn-llama-server`
- `allow-kill-llama-server`
- `allow-kill-all-llama-servers`
- `allow-get-random-port`
- `allow-read-gguf-metadata`
- `allow-check-server-health`
- `allow-download-file`
- `allow-cancel-download`
- `allow-extract-archive`
- `allow-remove-quarantine`
- `allow-fix-lib-symlinks`
