## Default Permission

Allows all vectordb plugin commands

#### This default permission set includes the following:

- `allow-initialize`
- `allow-upsert-meeting`
- `allow-upsert-chunks`
- `allow-delete-meeting`
- `allow-search`
- `allow-get-stale-meetings`
- `allow-get-indexed-ids`
- `allow-get-stats`
- `allow-get-meta`
- `allow-rebuild`
- `allow-graph-upsert`
- `allow-graph-traverse`
- `allow-graph-neighbors`
- `allow-graph-search`
- `allow-graph-delete-meeting`
- `allow-graph-stats`
- `allow-insert-usage`
- `allow-get-usage-summary`
