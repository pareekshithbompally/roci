# Name and icon

The code is MIT-licensed: use it, change it and ship your own app from it. The name **Roci**, the app icon and the bundle
identifier `ai.roci.roci` are not part of that licence; they identify the builds I sign and publish.

If you ship a fork, please give it its own name, icon, bundle identifier, signing identity and update feed, so no one
mistakes it for Roci or receives its updates.
